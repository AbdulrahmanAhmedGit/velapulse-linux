# VelaPulse
An independent Linux live-activity system: a Rust session service and an original GNOME Shell surface. Early development; see docs/ROADMAP.md for verified scope.

Conceptual inspiration: [Now Bar](https://github.com/nixesty/now-bar), an unrelated GPL-3.0 Windows project. No source, assets or branding were reused. VelaPulse is not affiliated with its author.

Build: `cargo build --release`. Runtime: Linux with a session D-Bus. Desktop integration instructions will be added alongside the implementation.
