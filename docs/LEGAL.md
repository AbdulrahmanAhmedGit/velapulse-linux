# Provenance and licensing
On 2026-10-26 the GitHub repository and license API identify nixesty/now-bar as GPL-3.0. This project is independently written, not a fork. Only the public feature description was studied. No reference implementation, fonts, icons, animations or assets were imported.

A web and GitHub repository name search was performed for VelaPulse. This is preliminary project-name research, not trademark clearance. MIT applies only to this project's original code. Dependencies retain their own licenses; a locked-dependency inventory accompanies release validation.

GitHub name search also found `XZ-AP/velapulse` without a description. The product name remains provisional, and the independent repository uses `velapulse-linux`; no exclusivity or trademark registration is claimed.

The locked dependency inventory records declared license expressions for the current graph, including the HTTP/TLS and bounded image decoder dependencies. Each dependency retains its own license and notice requirements, including Unicode and BSD-family terms where declared. See DEPENDENCIES.md. GTK4/GJS are separately provided LGPL libraries, GNOME Shell is separately provided GPL software, and gtk4-layer-shell is MIT. MIT licensing of original files does not relicense those dependencies. The repository does not bundle these runtime libraries.

Weather data uses Open-Meteo's documented API, with CC BY 4.0 attribution displayed in weather/brief views and setup documentation. The free service permits non-commercial use only; commercial distribution/use must arrange an appropriate service plan/provider. Geocoding uses the provider's GeoNames data. No Open-Meteo server code is copied or linked; its AGPL server implementation is separate from this HTTP client. Agent adapters implement documented event contracts using original code; no agent implementation, prompts or transcripts are bundled.
